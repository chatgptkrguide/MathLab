개인정보처리방침

시행일자: 2026년 5월 6일

MathLab(이하 "앱")은 사용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 방침은 MathLab 앱이 어떤 정보를 수집하고, 어떻게 이용하며, 어떻게 보호하는지를 설명합니다.

1. 수집하는 개인정보 항목

가. 회원가입 및 인증

  • 이메일 주소 (이메일/비밀번호 가입 시)
  • 비밀번호 (Firebase Authentication에서 단방향 해시 처리되어 저장되며, 앱은 평문을 보관하지 않습니다)
  • Google 계정 정보 (Google 로그인 시: 이메일, 이름, 프로필 사진)
  • Kakao 계정 정보 (Kakao 로그인 시: 이메일, 닉네임, 프로필 사진 — 사용자가 카카오 동의 화면에서 동의한 항목에 한함)
  • 익명 식별자 (게스트 로그인 시)

나. 사용자 프로필

  • 닉네임 (사용자가 직접 입력)
  • 프로필 이미지 (선택 사항)
  • 학습 목표 및 동기 (온보딩 시 입력)

다. 학습 활동 데이터

  • 풀이한 문제, 정답·오답 기록, 학습 시간
  • 경험치(XP), 스트릭, 레벨, 리그 정보
  • 보유 하트, 힌트 사용 이력
  • 업적 달성 이력

라. 결제 정보

  • 인앱결제(Google Play Billing) 사용 시 결제 영수증 토큰
  • 신용카드 번호 등 결제 수단 정보는 Google Play Billing이 처리하며, 앱은 직접 수집·저장하지 않습니다.

마. 카메라 및 사진 (관리자 권한 사용자에 한함)

  • 콘텐츠 제작·관리 권한을 가진 관리자(Admin) 계정에 한해, 문제·업적 등 콘텐츠 이미지를 등록할 때 기기의 카메라를 사용하거나 갤러리에서 사진을 선택할 수 있습니다.
  • 일반 학습자는 카메라 또는 사진 라이브러리에 접근하지 않으며, 권한 사용 화면도 표시되지 않습니다.
  • 촬영·선택된 이미지는 사용자의 명시적 동작에 의해서만 업로드되며, 백그라운드에서 수집되지 않습니다.

바. 자동 수집 정보

  • 디바이스 식별자, OS 버전, 앱 버전, 모델명
  • 푸시 알림 토큰 (Firebase Cloud Messaging)
  • 앱 사용 통계, 화면 이동 이벤트, 충돌 보고서 (Firebase Analytics / Crashlytics)

2. 개인정보의 이용 목적

  • 회원 식별, 인증, 부정 이용 방지
  • 학습 콘텐츠 제공 및 진도 관리
  • 게이미피케이션(XP, 스트릭, 리그, 업적) 기능 제공
  • 학습 리마인더 등 푸시 알림 발송 (사용자 동의 후)
  • 서비스 품질 개선을 위한 통계 분석 및 오류 수정
  • 인앱결제 처리, 환불·고객 문의 대응
  • 관리자의 학습 콘텐츠 등록·관리

3. 개인정보의 보유 및 이용 기간

  • 회원 탈퇴 시 또는 수집·이용 목적 달성 시 지체 없이 파기합니다.
  • 단, 관계 법령에 따라 일정 기간 보관이 필요한 경우 해당 기간 동안 보관합니다.
    • 전자상거래 등에서의 소비자보호에 관한 법률: 계약 또는 청약철회에 관한 기록 5년
    • 전자상거래 등에서의 소비자보호에 관한 법률: 대금결제 및 재화 등의 공급에 관한 기록 5년
    • 통신비밀보호법: 로그인 기록 3개월

4. 개인정보의 처리위탁 및 제3자 제공

앱은 안정적인 서비스 제공을 위해 다음 업체에 개인정보 처리를 위탁합니다.

수탁자위탁 업무보유 및 이용 기간
Google LLC (Firebase) 사용자 인증, 데이터베이스(Firestore), 푸시 알림(FCM), 사용 통계(Analytics), 충돌 보고(Crashlytics) 회원 탈퇴 또는 위탁계약 종료 시까지
Google LLC (Google Sign-In) 구글 계정 기반 로그인 처리 인증 처리 시점
Kakao Corp. 카카오 계정 기반 로그인 처리 (사용자가 선택한 경우에 한함) 인증 처리 시점
Google LLC (Google Play Billing) 인앱결제 처리 결제 처리 시점
Shorebird Inc. 코드 OTA 패치 배포 (익명 디바이스 단위 통계만 수집) 패치 전송 시점

위 위탁 외 목적으로는 사용자의 별도 동의 없이 개인정보를 제3자에게 제공하지 않습니다.

5. 사용자의 권리

사용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • 개인정보 열람, 수정, 삭제 요청
  • 회원 탈퇴 (계정 삭제 시 학습 데이터 일괄 삭제)
  • 개인정보 처리에 대한 동의 철회

요청은 아래 연락처로 보내주시면 지체 없이 처리합니다.

6. 개인정보의 안전성 확보 조치

  • 비밀번호 등 민감 정보는 Firebase Authentication에서 단방향 해시 처리됩니다.
  • 모든 통신은 HTTPS/TLS로 암호화됩니다.
  • Firebase Security Rules을 통해 데이터 접근 권한을 최소화합니다.
  • 운영자의 개인정보 접근 권한을 최소한으로 부여합니다.
